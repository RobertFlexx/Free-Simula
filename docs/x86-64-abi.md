# x86-64 ABI

Free Simula targets Linux x86-64 and implements the System V AMD64 conventions itself, thank you very much. This is the cheat sheet for how the machine actually sees your program: argument registers, stack frames, object layouts, and the little bits the compiler keeps in its wallet.

## Calling convention

Integer arguments follow the System V AMD64 sequence `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9`, which is the boring and correct thing to do. A method receiver occupies `rdi`; explicit method parameters begin at `rsi`. Integer, boolean, character, reference, descriptor pointer, enum, and address-sized values all ride in general-purpose registers.

Integer and pointer results come back in `rax`. Real values are internally represented as IEEE-754 binary64 bits in IR value locations and move through `xmm0` for arithmetic and conversion operations. Reals are not secretly 80-bit x87 values pretending to be portable.

The allocator may use caller-saved registers for short intervals and keeps `rbx`, `r12`, `r13`, `r14`, and `r15` for intervals that cross calls. Callee-saved registers are recorded per function and saved in deterministic order, because nondeterministic stack layouts are how compilers go to therapy.

## Stack frame

A function prologue saves `rbp`, establishes a frame pointer, saves the callee-saved registers it actually used, and reserves a 16-byte-aligned local frame. The frame contains spill slots, the optional method receiver, parameters copied out of registers, and the source-level local variables.

There is one shared epilogue target per function. Return statements move the result to `rax` and jump to that target. One epilogue, many returns, zero duplicated cleanup.

## Object layout

Every object begins with a two-word header:

| Offset | Size | Meaning |
|---:|---:|---|
| 0 | 8 | pointer to class RTTI record |
| 8 | 8 | pointer to class VMT |
| 16 | ... | inherited fields followed by local fields |

Fields are aligned to their type alignment. Derived objects retain the complete prefix object layout, so base methods can always use fixed offsets. That is the trade that keeps `QUA` and virtual dispatch boring in the best possible way.

## String layout

A string value is a pointer to a descriptor that is either immutable (literals in read-only data) or heap-backed:

| Offset | Size | Meaning |
|---:|---:|---|
| 0 | 8 | UTF-8 byte length |
| 8 | length | UTF-8 bytes |
| 8 + length | 1 | zero terminator |

The terminator exists for diagnostics and syscall interoperability. It is not included in equality or length, so `"abc"` and `"abc\0"` are not the same string and nobody has to explain that to a security auditor. Concatenation allocates one descriptor, checks the total size, copies both byte ranges, and writes a terminator.

## RTTI layout

Each class RTTI record begins with a parent RTTI pointer, object size, VMT slot count, name length, flags, and the UTF-8 class name. Parent pointers are relocated after read-only data receives its final virtual address, so they cannot dangle in the emitted file.

`QUA` compares the object's RTTI pointer with the requested RTTI and walks parent pointers until a match or null. Null remains null under a cast. A non-null failed cast enters the panic routine. That is the entire runtime safety story of the language, and it is short on purpose.

## Native threads

The runtime allocates a dedicated stack with `mmap`, places the child entry and context in a startup record, and invokes Linux `clone` with the VM, filesystem, file-descriptor, signal-handler, and thread-group sharing flags. The child transfers to the compiler-generated entry thunk and exits through the thread-exit syscall path. The runtime never pretends a thread ends by returning into a stack that was freed underneath it.

## Syscalls

The embedded runtime directly uses Linux x86-64 syscall numbers for read, write, mmap, munmap, clone, exit, and exit-group. Executables do not require an ELF interpreter segment or a dynamic section, because the compiler is its own operating system interface, in a modest and carefully scoped way.
